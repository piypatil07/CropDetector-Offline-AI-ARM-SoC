- [x] GitHub-ready Android source tree, model artifacts and documented reproducibility checks assembled
- [x] Available Stage A / Stage B research notebooks included
- [x] Real device results separated by connectivity/thermal context
- [ ] **Review licenses for ALL redistributed models and data-derived assets**; choose project source-code LICENSE
- [ ] Test `cd android && ./gradlew assembleDebug --no-configuration-cache` from a fresh checkout
- [ ] Record/check setup on target ARM phone with model weights installed and verified
- [ ] Ask faculty mentor to review prototype and claims (challenge recommendation)
- [ ] Create GitHub/GitLab repository and set visibility **Public**; paste URL in submission form
- [ ] Record 2-minute **MP4, 1920×1080, 16:9** demonstration and upload with **Public** visibility; paste URL
- [ ] Finish technical report emphasizing methodology/results/ARM hardware optimization; submit **PDF or DOCX**
- [ ] Replace placeholders and confirm all human/team identities are correct
- [ ] Include original Stage C training/export notebook if available
- [ ] Validate advisory response safety and disclose uncertainty in video
