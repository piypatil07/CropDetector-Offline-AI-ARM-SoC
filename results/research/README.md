# Experiment summary files

The JSON summaries are extracted unchanged from previously collected Phase 9 result ZIPs: Stage A Part 3, Stage B Part 1 and Stage B Part 2. They are historical experiment reports and **are not app runtime outputs**. Stage B is not deployed. Check the experimental dataset composition and test-split methodology in the corresponding notebooks before reporting results.

Do not use Stage A near-perfect in-domain development accuracy as plant validation performance on unseen field photos. Do not treat Stage B PlantVillage development accuracy as external field accuracy.
